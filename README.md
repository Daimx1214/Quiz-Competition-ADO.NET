# Quiz Competition System - ASP.NET Core Web API

A backend Quiz Competition System developed using **ASP.NET Core Web API**, **C#**, **Entity Framework Core**, and **Microsoft SQL Server**. The project provides RESTful APIs to manage quizzes, questions, participants, and quiz-related records.

## 🚀 Technologies Used

- ASP.NET Core Web API (.NET 8)
- C#
- Entity Framework Core
- Microsoft SQL Server
- Swagger (OpenAPI)

## ✨ Features

- Create, update, delete, and retrieve quizzes
- Manage quiz questions
- Manage participants
- CRUD operations using REST APIs
- SQL Server database integration
- API testing with Swagger
- Clean and organized project structure

## 🛠️ Getting Started

### Prerequisites

- .NET 8 SDK
- Microsoft SQL Server
- Visual Studio 2022

### Installation

1. Clone the repository

```bash
git clone https://github.com/Daimx1214/QuizCompetition.git
```

2. Open the project in Visual Studio.

3. Update the SQL Server connection string in **appsettings.json**.

4. Apply Entity Framework Core migrations.

```bash
Update-Database
```

or

```bash
dotnet ef database update
```

5. Run the project.

6. Open Swagger in your browser.

```
https://localhost:{port}/swagger
```
